# 🤖 AIGENT – Desktop Virtual Assistant

**AIGENT (Artificial Intelligence Guidance and Enhanced Network Technology)** is a smart virtual assistant inspired by JARVIS from Iron Man. It integrates **facial recognition**, **NLP**, **task automation**, and more to deliver an intelligent and interactive desktop experience.

---

## 🔧 Features

- 🧠 Conversational AI using NLP
- 👁️ Facial Recognition for secure access
- 🎯 Task Automation: open apps, search the web, etc.
- 🖐️ Hand Gesture Detection
- 🎨 AI-based Image Generation

---

## 🗂️ Project Structure

```
AIGENT/
│
├── Main_Aigent.py         # Main script to run the assistant
├── face_detection.py      # Facial recognition module
├── search_now.py          # Web search functionality
├── handges.py             # Hand gesture detection
├── Gen_img.py             # Image generation with AI
├── requirements.txt       # Python dependencies
└── README.md              # Project documentation
```

---

## 🚀 How to Run

1. **Clone the repository:**

```bash
git clone https://github.com/RiyalNotHim/AIGENT.git
cd AIGENT
```

2. **Install the dependencies:**

```bash
pip install -r requirements.txt
```

3. **Run the main script:**

```bash
python Main_Aigent.py
```

Ensure all required modules (`face_detection`, `search_now`, `handges`, `Gen_img`) are present and correctly imported.
